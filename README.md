# ୨୧ CSS Unit Converter

Un conversor de unidades CSS (**PX ↔ EM**) desarrollado en Java. El proyecto permite realizar conversiones bidireccionales de píxeles a unidades relativas `em` basándose en un tamaño de fuente base configurable.

---

## ୨୧ Características

- **Conversión de PX a EM:** Convierte valores absolutos en píxeles a unidades relativas `em`.
- **Conversión de EM a PX:** Calcula la equivalencia en píxeles a partir de un valor `em`.
- **Base configurable:** Permite definir un tamaño de fuente base en píxeles (por defecto `16px`).
- **Doble interfaz:**
  - **Consola / CLI:** Interacción mediante la terminal usando `Scanner`.
  - **Interfaz Gráfica (GUI):** Interfaz amigable desarrollada con **Java Swing**.

---

## ୨୧ Tecnologías Utilizadas

- **Lenguaje:** Java 21 (JDK 21)
- **GUI:** Java Swing / AWT
- **Control de Versiones:** Git & GitHub
